# Source audit closure — 0.1.2

The independent 18/10/2026 audit found five P1 and seven P2 items in 0.1.1.
This record describes the final repairs; current executable evidence is in
[QA_REPORT.md](QA_REPORT.md). Historical v1.2 source is unchanged.

| Finding | Repair | Verification |
|---|---|---|
| F01 page completeness | Integer page arithmetic, cardinality and request metadata checks | Contradictory/short pages rejected |
| F02 task switching | Scope-only continuation and active intent | Order/payment/refund switch regression; search resumes |
| F03 quality gates | Typed registry locals, real jsonschema stubs, lint/format repairs | Ruff/Mypy checks |
| F04 ignored reports | Local reports excluded; maintained evidence versioned here | Manifest export and Git-ignore check |
| F05 parser failures | JSON depth limit, non-finite rejection, typed upstream errors | Transport and HTTP fallback tests |
| F06 slot removal | Typed REMOVE/CLEAR, deterministic ordering and budget invariant | Domain and HTTP reset/filter tests |
| F07 invalid quantities | Recognize numeric quantities before range validation | 0/21/negative/large text clarification |
| F08 invalid optimizer values | Finite nonnegative Decimal, strict counts/status validation | Negative/NaN/Infinity/count/tie-break tests |
| F09 family leakage | Connected group/family components | Both keys disjoint, including transitive links |
| F10 artifact hash drift | Write and hash the same canonical UTF-8 bytes | Actual file SHA-256 assertions |
| F11 Windows snapshot verifier | POSIX canonical paths; ignore generated bytecode | Original 49 SHA-256 values |
| F12 side-effect GET guard | Shared route denial at gateway and transport; reject mutation aliases | Denied before transport in temporary configs |

Additional hardening: global tool deadline, safe request tracing, pinned hash
exports, dependency vulnerability scan, portable isolated wheel smoke and a
Windows/Linux CI definition. Framework pins were updated after the runtime audit
reported advisories in pydantic-settings and Starlette; the post-update audit is
recorded independently, not inferred from a version number.

F08 closes invalid domain inputs. It does not claim the pure optimizer has live
quota/seat/freshness integration. F06 closes supported slot clearing; it does not
claim full v1.2 REFER/ADD/ontology implementation. Those product capabilities stay
blocked as listed in [BACKLOG.md](BACKLOG.md), with all business tools disabled.
